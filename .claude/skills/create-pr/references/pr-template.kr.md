# PR 본문 템플릿 (kr)

`<...>` 자리표시자를 모두 채워 사용한다. 해당하지 않는 섹션은 삭제하지 않고 "해당 없음"으로 둔다.

```markdown
## 개요
<이 PR이 무엇을, 왜 하는지 1~3문장>

## 변경 사항
- <주요 변경 1>
- <주요 변경 2>

## 변경 유형
- [ ] feat: 새 기능
- [ ] fix: 버그 수정
- [ ] refactor: 동작 변화 없는 구조 개선
- [ ] chore: 빌드·설정·문서 등

## 테스트
- [ ] <실행한 테스트/검증 방법과 결과>

## 스크린샷 / 참고 자료
<UI 변경 시 스크린샷, 없으면 "해당 없음">

## 관련 이슈
<Closes #번호 / 없으면 "해당 없음">

## 리뷰어 참고 사항
<중점적으로 봐야 할 부분, 알려진 한계, 후속 작업. 없으면 "해당 없음">
```
