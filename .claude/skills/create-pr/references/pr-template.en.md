# PR Body Template (en)

Replace every `<...>` placeholder. Keep sections that don't apply and mark them "N/A" instead of deleting them.

```markdown
## Summary
<What this PR does and why, in 1-3 sentences>

## Changes
- <Key change 1>
- <Key change 2>

## Type of change
- [ ] feat: new feature
- [ ] fix: bug fix
- [ ] refactor: restructuring without behavior change
- [ ] chore: build, config, docs, etc.

## Testing
- [ ] <Tests/verification performed and results>

## Screenshots / References
<Screenshots for UI changes, otherwise "N/A">

## Related issues
<Closes #number / "N/A" if none>

## Notes for reviewers
<Areas needing attention, known limitations, follow-ups. "N/A" if none>
```
